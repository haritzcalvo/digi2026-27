GUÍA DE ADMINISTRACION DEL SISTEMA

Bienvenido a esta guía básica sobre administracion de sistema informatico en red

1.INSTALACION DEL SIST. OPERATIVO

Primero, se debe elegir el sistema operativo adecuado según las necesidades del entorno

1.1 Requisitos previos

Verifica el hardware,la compatibilidad y realiza una copia de seguridad

1.2 Proceso de instalacion

Utiliza un medio de instalacion(USB,DVD) y sigue los pasos del asistente

2. Configuración de red

Una vez instalado el sistema, se debe configurar la red para permitir la conectibidad

2.1Dirección IP y DNS

Configura una IP estatica o dinámica y define los servidores del DNS

2.2 Prueba de conectibidad

Usa comandos como ping o ... para verificar la conexión
